# Analyzing-and-Resolving-a-Potential-Brute-Force-Attack-As-a-SOC-L2
Analyzed authentication logs to identify repeated failed login attempts, suspicious IP addresses, targeted accounts, and attack patterns. Validated the severity, determined the activity was malicious, and performed appropriate containment and remediation. Documented the findings and actions taken before resolving the incident.
